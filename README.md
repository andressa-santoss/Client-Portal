# ClientPortal — Landing Page

Landing page interativa do ClientPortal, criada somente com HTML, CSS e JavaScript.

## Como rodar

1. Abra a pasta no VS Code.
2. Abra `index.html` no navegador.
3. Para uma experiência melhor, instale a extensão **Live Server** no VS Code.
4. Clique com o botão direito em `index.html` → **Open with Live Server**.

## Estrutura

```text
clientportal-landing/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Interações

- Menu responsivo para celular
- Navbar muda ao rolar
- Animações de entrada das seções
- Demonstração em modal
- Tabs de Projetos / Mensagens / Financeiro
- Cards do dashboard clicáveis
- FAQ expansível
- Toasts de feedback
- Efeito de profundidade no dashboard
- Scroll suave
- Layout responsivo
